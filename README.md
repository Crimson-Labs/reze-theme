# reze-theme

Clean, modern Midnight-style Discord theme with rounded UI, black/purple palette, and a Reze-inspired anime PNG background.

## Files

- `reze.theme.css` - main theme file
- `midnight.css` - self-hosted theme module build
- `reze-bg.png` - custom background image (PNG)

## GitHub-ready URLs in theme

- Theme source:
  `https://github.com/Crimson-Labs/reze-theme/blob/main/reze.theme.css`
- Module import:
  `https://raw.githubusercontent.com/Crimson-Labs/reze-theme/main/midnight.css`
- Background:
  `https://raw.githubusercontent.com/Crimson-Labs/reze-theme/main/reze-bg.png`

## Install (Vencord / BetterDiscord)

1. Copy `reze.theme.css` into your themes folder.
2. Enable the theme.
3. Push this exact root structure to `Crimson-Labs/reze-theme` so import/background URLs work.
